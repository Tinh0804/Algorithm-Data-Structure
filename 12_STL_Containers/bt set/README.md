# Bài Tập std::set

## 1. Thông tin tệp mã nguồn
- [`bt set.cpp`](./bt set.cpp)
- **Thư mục chuyên đề**: `DSA/12_STL_Containers/bt set/`
- **Ngôn ngữ**: C/C++ (Chuẩn C++11 trở lên)

## 2. Mục tiêu & Tóm tắt bài toán
Ứng dụng std::set đếm số phần tử phân biệt trong mảng.

---

## 3. Ý tưởng & Phương pháp giải thuật
### Phương án tiếp cận:
Chèn các phần tử vào set và lấy kích thước.

### Các bước thực hiện chi tiết:
1. Khởi tạo dữ liệu và đọc đầu vào theo định dạng bài toán.
2. Thực hiện thuật toán cốt lõi: Chèn các phần tử vào set và lấy kích thước.
3. Cập nhật trạng thái và tính toán kết quả.
4. Xuất kết quả đầu ra màn hình.
